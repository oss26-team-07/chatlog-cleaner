    Sort messages by time, keeping the original order for equal times.

    Messages with a normalized time key.

    		 required

    Returns:

    Type Description
    list[dict]

    A new sorted list. The input list is not changed.

    Examples:

    >>> msgs = [{'time': '2026-11-09 14:06', 'text': 'b'},
...         {'time': '2026-11-09 14:05', 'text': 'a'}]
